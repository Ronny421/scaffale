# Scaffale

App per catalogare i libri di casa: scansione ISBN e copertine, generi, autori, segnalibro, export PDF. Funziona offline ed è installabile su Android (PWA).

Apri https://ronny421.github.io/scaffale/ con Chrome su Android → menu ⋮ → "Aggiungi a schermata Home".
